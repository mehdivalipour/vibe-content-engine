اتصال‌های اختیاری

موتور بدون ثبت‌نام با Gutenberg، Wikisource، Wikimedia، NASA، LibriVox و Internet Archive کار می‌کند. برای Smithsonian و Pixabay فقط Secret اضافه می‌شود. این نسخه هیچ اتصال Gemini/OpenAI یا LLM ندارد.

دستورهای Cloudflare

npm install
# منابع اختیاری
npx wrangler secret put SI_API_KEY
npx wrangler secret put PIXABAY_API_KEY

# انتشار
npm run deploy
